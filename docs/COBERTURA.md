## Otros materiales presentes en la clase

- **INTRO**: otro ejemplo introductorio de texto a voz. En esta colección se incluye **IMM1**, que cubre esa experiencia.
- **tdf_esp**: variante en español del ejercicio TF-IDF; la colección contiene el repositorio TF_IDF.
- **lstmnlp**: ejercicio de modelo de lenguaje y entrenamiento en casa; no hay un despliegue propio incorporado para este repositorio.
- **hist_inf**: ejemplo de historias con imágenes en el ejercicio de un contexto real; no está incorporado como app independiente.
- **cerradura_gestos**: integración con reconocimiento de gestos y un modelo propio; no está incorporada ni se ha verificado con hardware.
- Los cuadernos de Colab, ejemplos de Wokwi y recursos de entrenamiento no se cuentan automáticamente como apps desplegadas.

Estos elementos requieren contrastar el alcance exigido por el profesor. No se han marcado como completados ni se ha supuesto que son opcionales.

## Cómo comprobar la evidencia

Abrir cada demo, realizar una entrada propia y conservar el resultado junto con la explicación de entrada, procesamiento y salida. Los servicios de voz/traducción requieren conexión; las apps de OpenAI requieren una clave con acceso; las experiencias IoT requieren broker y dispositivo o emisor. Las pruebas con dobles de servicios no equivalen a una ejecución real de esos servicios.
